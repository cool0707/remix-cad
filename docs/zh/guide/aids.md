# 辅助显示

辅助显示帮助你更精确地定位点、方向和对象。

## 对象捕捉（OSNAP）

对象捕捉会在光标靠近可捕捉位置时，自动吸附到这些点上，并显示捕捉标记。

支持的捕捉模式：

| 模式 | 标记 | 说明 |
|---|---|---|
| EndPoint | 矩形 | 线段端点 |
| MidPoint | 三角形 | 线段中点 |
| Center | 圆形 | 圆/圆弧/椭圆圆心 |
| Quadrant | 菱形 | 圆的四个象限点 |
| Nearest | 十字 | 离光标最近的点 |
| Intersection | × | 两条线的交点 |

OSNAP 在状态栏上可以快速开关，点击可以进入详细配置面板选择要启用的捕捉模式。

## 正交模式（ORTHO）

开启后，限制下一条线只能沿水平或垂直方向绘制。适用于绘制轴对齐的矩形、正三角形等。

- 快捷键：`F8`（如果支持）
- 读写模式桌面端在状态栏点击切换开关

## 角度吸附（POLAR）

开启后，从上一点到光标的方向会吸附到所设角度的倍数方向。点击状态栏按钮旁的下箭头可选择“吸附角度”：每 90°、45°、30°、22.5°、18°、15°、10° 或 5°（默认每 90°）。

即使角度吸附处于关闭状态，按住 `Shift` 时也会吸附到相同的角度。

与正交模式同时开启时，水平和垂直方向也会加入吸附方向。

该功能相当于 CAD 中的“极轴追踪”（AutoCAD 的 POLAR），角度保存在系统变量 POLARANG 中。

## 动态输入（DYN）

在光标附近显示浮动输入框。命令执行过程中，可以直接在输入框里键入数值（距离、角度等）而不必操作命令行。

## 橡皮筋预览

几乎所有绘图命令在你移动光标时，都会实时显示一条从"上一个点"到"当前光标"的临时预览线段（橡皮筋），帮助你判断方向和长度。
