# 보조 표시

보조 표시는 점, 방향, 객체를 더 정확하게 파악할 수 있게 도와줍니다.

## 객체 스냅(OSNAP)

객체 스냅은 커서가 스냅 가능한 위치에 가까워지면 자동으로 해당 점에 흡착되며 스냅 표시를 보여줍니다.

지원하는 스냅 모드:

| 모드 | 표시 | 설명 |
|---|---|---|
| EndPoint | 사각형 | 선분 끝점 |
| MidPoint | 삼각형 | 선분 중점 |
| Center | 원 | 원/원호/타원 중심 |
| Quadrant | 마름모 | 원의 네 사분점 |
| Nearest | 십자 | 커서에 가장 가까운 점 |
| Intersection | × | 두 선의 교점 |

OSNAP은 상태 표시줄에서 빠르게 켜거나 끌 수 있으며, 클릭하면 상세 설정 패널로 진입하여 활성화할 스냅 모드를 선택할 수 있습니다.

## 직교 모드(ORTHO)

켜면 다음 선을 수평 또는 수직 방향으로만 그릴 수 있습니다. 축 정렬된 사각형, 정삼각형 등을 그릴 때 적합합니다.

- 단축키: `F8`(지원되는 경우)
- 상태 표시줄 클릭으로 토글

## 각도 스냅(POLAR)

켜면 이전 점에서 커서로 향하는 방향이 설정한 각도의 배수 방향에 스냅됩니다. 상태 표시줄 버튼 옆의 아래 화살표에서 스냅 각도를 90°, 45°, 30°, 22.5°, 18°, 15°, 10°, 5° 간격 중에서 선택할 수 있습니다(기본값은 90° 간격).

각도 스냅이 꺼져 있어도 `Shift`를 누르고 있는 동안에는 같은 각도에 스냅됩니다.

직교 모드와 함께 켜면 수평·수직 방향도 스냅 방향에 추가됩니다.

CAD의 "극좌표 추적"(AutoCAD의 POLAR)에 해당하는 기능이며, 각도는 시스템 변수 POLARANG에 저장됩니다.

## 동적 입력(DYN)

커서 근처에 플로팅 입력란을 표시합니다. 명령 실행 중 명령줄을 조작하지 않고 입력란에 직접 수치(거리, 각도 등)를 입력할 수 있습니다.

## 고무줄 미리보기

거의 모든 그리기 명령은 커서를 이동할 때 "이전 점"에서 "현재 커서"까지 임시 미리보기 선분(고무줄)을 실시간으로 표시하여 방향과 길이를 판단하는 데 도움을 줍니다.
